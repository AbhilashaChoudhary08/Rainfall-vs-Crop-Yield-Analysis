# Rainfall-vs-Crop-Yield-Analysis
This project analyzes the relationship between rainfall patterns and crop yield using Python-based data analysis and visualization techniques, along with an interactive Tableau dashboard. The objective is to understand how variations in rainfall influence agricultural productivity over different states of India and to present insights through clear and effective visualizations.
<br>

##  Project Overview
This project focuses on analyzing the relationship between **rainfall patterns and crop yield** using **Python-based data analysis and visualization techniques**, along with an **interactive Tableau dashboard**.  
The goal is to understand how variations in rainfall influence agricultural productivity and to present insights through clear and effective visualizations.

This project was developed as part of a **GE – Data Engineering / Data Visualization** coursework.

##  Dataset Description
The project uses structured datasets containing:
- Rainfall data (year-wise / region-wise)
- Crop yield data for selected crops

The data was cleaned and preprocessed using Python to handle missing values, inconsistencies, and formatting issues before analysis.

---

##  Methodology
The project follows these key steps:

1. **Data Collection & Loading**
   - Importing rainfall and crop yield datasets using Pandas

2. **Data Cleaning & Preprocessing**
   - Handling missing and null values
   - Standardizing column names and data types
   - Filtering relevant records

3. **Exploratory Data Analysis (EDA)**
   - Understanding rainfall trends over time
   - Analyzing crop yield variations
   - Identifying patterns and anomalies

4. **Data Visualization (Python)**
   - Line charts for rainfall trends
   - Bar charts for crop yield comparison
   - Scatter plots to study rainfall vs crop yield relationship

5. **Dashboard Creation (Tableau)**
   - Interactive visualizations combining rainfall and crop yield data
   - Filters for better data exploration and insight generation
